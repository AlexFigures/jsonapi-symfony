JsonApiBundle
=============

JSON:API 1.1 resources, Doctrine or custom persistence, Atomic Operations,
profiles and bounded relationship reads for Symfony.

The reviewed 1.0 contract is verified by bundle compatibility CI and independent
applications. Stable targets are Symfony 7.4 and 8.1; Symfony 8.2-dev is a forward
compatibility target. Package publication follows the release checklist.
