JsonApiBundle
=============

JSON:API 1.1 resources, Doctrine or custom persistence, Atomic Operations,
profiles and bounded relationship reads for Symfony.

The 1.0 line is in stabilization. Platform support requires bundle compatibility
CI and independently verified version-pinned applications.
